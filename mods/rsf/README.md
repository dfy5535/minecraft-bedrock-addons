## 简介

纯指令「选址 + 逐块建造 + 防重叠 + 回执」框架，全地形 4224 座建筑。

**内容规模**

- 87 群系 → 33 地形主题 × 每主题 128 座 = 4,224 座纯指令建筑
- 4,275 个 mcfunction 文件

## 安装

1. 下载上面的 `.mcaddon` 文件
2. 双击导入（或在游戏内「设置 → 存储 → 资源包/行为包」导入）
3. 新建世界或进入已有世界，**同时启用行为包与资源包**
4. 若提示缺少依赖，请确认两个包都启用了
