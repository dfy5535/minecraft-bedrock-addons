## 一、发现的真 bug（已修复 + 已真机验证）

### DeepVein：24 种矿石挖掉后**不产经验球**

| 项 | 内容 |
|---|---|
| 位置 | `DeepVein_BP_bp/scripts/main.js` 的 `world.afterEvents.playerBreakBlock` |
| 根因 | **`playerBreakBlock` 是 after 事件，此时 `ev.block` 已经是 `minecraft:air`**，我原来用 `block.typeId` 查经验表 → 永远查不到 → 经验球一个都不生成 |
| 证据 | 独立探针包实测记录：`[PROBE] playerBreakBlock minecraft:air by vprobe1` |
| 修法 | 改用 **`brokenBlockPermutation.type.id`**（1.17.0 官方 API，与 LuckyClover 原有写法一致） |
| 版本 | v2.2.2 → **v2.2.3**（UUID 换新） |

**修复后真机证据**（同一探针）：
```
[PROBE] playerBreakBlock minecraft:air by vfix1
[PROBE] spawned minecraft:item
[PROBE] spawned minecraft:xp_orb ×5      ← 经验球正常生成
```
另：`/clear vfix1 deepvein:raw_titanium` → `removing 1 items` → 掉落物也正确。

### 同类问题排查（全 MOD）

| MOD | 破坏事件 | 取方块类型的方式 | 结论 |
|---|---|---|---|
| DeepVein | `afterEvents.playerBreakBlock` | 原 `block.typeId` | ❌ 已修 |
| LuckyClover | `afterEvents.playerBreakBlock` | `brokenBlockPermutation.type.id` | ✅ 本来就对 |
| LuckyBlock | `beforeEvents.playerBreakBlock` | `block.typeId`（before 事件方块仍在） | ✅ 安全 |
| Zombie | 无此事件 | — | — |
